- Improved reproducibility and project readability through package architecture, test coverage, experiment configs, and documentation tailored for research and portfolio review.

## Interview Narrative

If someone asks why this project stands out, focus on three themes:

1. You identified architecture problems in the notebook and redesigned the system instead of only tuning a model.
2. You treated the work as an experiment platform, not a one-off script.
3. You created a repository that lets another engineer reproduce, extend, and evaluate your results cleanly.
